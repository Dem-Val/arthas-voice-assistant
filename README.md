# 🎙️ Лина — Голосовой ИИ-Помощник для Windows

Умный голосовой помощник нового поколения. В отличие от стандартных скриптовых ассистентов с жестко заданными путями, **Лина** использует:
- **Мозг нейросети Google Gemini (Function Calling):** понимает любые естественные формулировки («Лина, вруби музыку на ютубе», «открой телегу», «выруби звук», «найди файл отчета»).
- **Динамический сканер приложений:** сама сканирует ярлыки в меню «Пуск», на рабочем столе и в реестре Windows, находя нужную программу без ручной настройки путей.
- **Инструменты прямого контроля системы:** управление звуком, медиа-клавишами (Play/Pause/Next), окнами, скриншотами и питанием.
- **Естественный голос:** озвучка через нейронный движок Microsoft Neural TTS.

---

## 🚀 Быстрый запуск

1. **Ключ Gemini API:**
   * Получите бесплатный ключ на [Google AI Studio](https://aistudio.google.com/app/apikey).
   * Откройте файл `.env` и вставьте ваш ключ:
     ```env
     GEMINI_API_KEY=ваш_ключ_здесь
     ```
2. **Запуск:**
   * Дважды кликните по файлу **`start.bat`** (или выполните команду в консоли: `.venv\Scripts\python main.py`).

## 💬 Примеры команд

Просто скажите:
* *«Лина, открой телеграм»* (или *«Лина, запусти телегу»*)
* *«Лина, открой калькулятор»*
* *«Лина, сделай звук потише»* / *«Лина, громкость 50 процентов»*
* *«Лина, выключи звук»*
* *«Лина, включи на ютубе рок-музыку»*
* *«Лина, найди файл сметы»*
* *«Лина, сверни все окна»*
* *«Лина, сделай скриншот»*
* *«Лина, кто написал Войну и Мир?»* (обычный вопрос — ответит голосом)

## ⚙️ Структура проекта

```
Гол. помощник/
│
├── .env                  # Настройки и API-ключ Gemini
├── config.py             # Загрузка конфигурации
├── main.py               # Главный цикл голосового помощника (STT -> Brain -> TTS)
├── test_assistant.py     # Режим тестирования текстом через консоль
├── start.bat             # Скрипт быстрого запуска для Windows
├── requirements.txt      # Зависимости Python
│
├── agent/
│   └── brain.py          # Интеграция с Google Gemini и вызов функций (Tool Calling)
│
├── tools/
│   ├── app_scanner.py    # Динамический поиск и запуск любых программ Windows
│   ├── system_control.py # Звук, медиа, окна, скриншоты, блокировка ПК
│   ├── file_search.py    # Поиск файлов в документах и на дисках
│   └── web_tools.py      # Поиск в Google, YouTube, открытие сайтов
│
└── voice/
    ├── stt.py            # Распознавание речи и реакция на имя "Лина"
    └── tts.py            # Озвучка ответов голосом Светланы (Microsoft Neural)
```

## 💡 Как сменить имя или голос?
Откройте файл `.env` и измените значения:
* `ASSISTANT_NAME=ева` (или любое другое имя)
* `VOICE_NAME=ru-RU-DmitryNeural` (мужской голос) или `ru-RU-SvetlanaNeural` (женский голос)

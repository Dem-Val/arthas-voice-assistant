# ⚔️ Гладиатор — Голосовой ИИ-Помощник для Windows

Умный и мощный голосовой ассистент нового поколения. В отличие от стандартных скриптовых ассистентов с жестко заданными путями, **Гладиатор** использует:
- **Мозг нейросети Google Gemini (Function Calling):** понимает любые естественные формулировки («Гладиатор, вруби музыку на ютубе», «открой оперу», «выруби звук», «найди файл отчета»).
- **Динамический сканер приложений:** сам сканирует ярлыки в меню «Пуск», на рабочем столе и в реестре Windows, находя нужную программу без ручной настройки путей.
- **Инструменты прямого контроля системы:** управление звуком, медиа-клавишами (Play/Pause/Next), окнами, скриншотами и блокировкой ПК.
- **Естественный мужской голос:** озвучка через нейронный движок Microsoft Dmitry Neural + 100% офлайн-резерв через Windows SAPI5 (работает даже без интернета).

## 🚀 Быстрый запуск

### Вариант 1: Через готовый файл `Gladiator.exe`
1. Скачайте файл **`Gladiator.exe`** из раздела [Releases](https://github.com/Dem-Val/gladiator-voice-assistant/releases).
2. Запустите двойным кликом.
3. При первом запуске введите бесплатный ключ Gemini API (получить можно на [Google AI Studio](https://aistudio.google.com/app/apikey)).

### Вариант 2: Запуск из исходного кода
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Dem-Val/gladiator-voice-assistant.git
   cd gladiator-voice-assistant
   ```
2. Запустите `start.bat`.

## ⚙️ Структура проекта

```
gladiator-voice-assistant/
│
├── .env                  # Настройки, API-ключ Gemini и параметры прокси
├── config.py             # Загрузка конфигурации
├── main.py               # Главный цикл голосового помощника (STT -> Brain -> TTS)
├── test_assistant.py     # Режим тестирования текстом через консоль
├── start.bat             # Скрипт быстрого запуска для Windows
├── requirements.txt      # Зависимости Python
│
├── agent/
│   └── brain.py          # Интеграция с Google Gemini и вызов функций (Tool Calling)
│
├── tools/
│   ├── app_scanner.py    # Динамический поиск и запуск любых программ Windows
│   ├── system_control.py # Звук, медиа, окна, скриншоты, блокировка ПК
│   ├── file_search.py    # Поиск файлов в документах и на дисках
│   └── web_tools.py      # Поиск в Google, YouTube, открытие сайтов
│
└── voice/
    ├── stt.py            # Распознавание речи и реакция на имя "Гладиатор"
    └── tts.py            # Озвучка ответов голосом Дмитрия (Microsoft Neural + Offline SAPI5)
```

## 🌍 Обход региональных ограничений (для пользователей из РФ):
Google блокирует прямые запросы к AI Studio с российских IP. Для решения:
1. **Включите любой VPN на ПК** (WireGuard, Amnezia, VLESS, Outline и др.) — ключ Gemini заработает сразу.
2. **Или укажите прокси в `.env`**: `GEMINI_PROXY=http://127.0.0.1:10809`.
3. **Или используйте OpenRouter (без VPN)**: укажите `OPENAI_API_KEY` в файле `.env`.

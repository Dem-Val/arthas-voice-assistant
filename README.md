# 👑 Артас — Голосовой ИИ-Помощник для Windows

Умный и могущественный голосовой ассистент нового поколения. В отличие от стандартных скриптовых ассистентов с жестко заданными путями, **Артас** использует:
- **Мозг нейросети Google Gemini (Function Calling):** понимает любые естественные формулировки («Артас, включи музыку на ютубе», «открой оперу», «выруби звук», «найди файл отчета»).
- **Динамический сканер приложений:** сам сканирует ярлыки в меню «Пуск», на рабочем столе и в реестре Windows, находя нужную программу без ручной настройки путей.
- **Инструменты прямого контроля системы:** управление звуком, медиа-клавишами (Play/Pause/Next), окнами, скриншотами и блокировкой ПК.
- **Естественный мужской голос:** озвучка через нейронный движок Microsoft Dmitry Neural + 100% офлайн-резерв через Windows SAPI5 (работает даже без интернета).

## 🚀 Быстрый запуск

### Вариант 1: Через готовый файл `Arthas.exe` (в 1 клик)
1. Скачайте файл **`Arthas.exe`** из раздела [Releases](https://github.com/Dem-Val/arthas-voice-assistant/releases).
2. Запустите двойным кликом.
3. При первом запуске введите бесплатный ключ:
   * **⚡ Groq Cloud (Рекомендуется для РФ, без VPN, 100% бесплатно):** [console.groq.com/keys](https://console.groq.com/keys) (ключ `gsk_...`).
   * **🌐 Google Gemini API (требует VPN в РФ):** [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey).

### Вариант 2: Запуск из исходного кода
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Dem-Val/arthas-voice-assistant.git
   cd arthas-voice-assistant
   ```
2. Запустите `start.bat`.

## ⚙️ Структура проекта

```
arthas-voice-assistant/
│
├── .env                  # Настройки, API-ключ Gemini и параметры прокси
├── config.py             # Загрузка конфигурации
├── main.py               # Главный цикл голосового помощника (STT -> Brain -> TTS)
├── test_assistant.py     # Режим тестирования текстом через консоль
├── start.bat             # Скрипт быстрого запуска для Windows
├── requirements.txt      # Зависимости Python
│
├── agent/
│   └── brain.py          # Интеграция с Google Gemini и вызов функций (Tool Calling)
│
├── tools/
│   ├── app_scanner.py    # Динамический поиск и запуск любых программ Windows
│   ├── system_control.py # Звук, медиа, окна, скриншоты, блокировка ПК
│   ├── file_search.py    # Поиск файлов в документах и на дисках
│   └── web_tools.py      # Поиск в Google, YouTube, открытие сайтов
│
└── voice/
    ├── stt.py            # Распознавание речи и реакция на имя "Артас"
    └── tts.py            # Озвучка ответов голосом Дмитрия (Microsoft Neural + Offline SAPI5)
```

## 🌍 Работа без VPN и региональных ограничений (для пользователей из РФ):
1. **⚡ Рекомендуется: Groq Cloud (без VPN, 100% бесплатно навсегда):**
   * Получите ключ на [console.groq.com/keys](https://console.groq.com/keys).
   * Вставьте в `.env`: `OPENAI_API_KEY=gsk_...`
   * Работает прямо из РФ с максимальной скоростью в мире (0.3-0.5с).
2. **🌐 Google Gemini (требует VPN):**
   * Включите любой системный VPN на ПК (WireGuard, Amnezia, VLESS, Outline и др.) — ключ Gemini заработает сразу.
   * Или укажите локальный прокси в `.env`: `GEMINI_PROXY=http://127.0.0.1:10809`.
